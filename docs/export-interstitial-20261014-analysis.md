# 내보내기 전면 광고 분석

2026-10-14, orchestrator=Codex. 사용자는 GIF 저장·공유에 전면 광고를 제안했고, 이어 단체방 공유 텍스트 생성과 `.sq` 저장도 같은 대상으로 지정했다. 앞선 제안의 닫기 후 계속, 실패·오프라인 통과, 작업 간 공통 10분 간격을 적용한다. 외부 AdMob 운영 ID는 아직 제공되지 않아 Google 테스트 ID로 구현한다.

## 범위

Android에서 GIF 저장·공유, 단체방 공유 텍스트 생성, `.sq` 파일 내보내기의 결과물 준비가 끝나는 시점에 전면 광고를 최대 한 번 표시한다. 기기 내 자동저장·복원·PNG·공유 URL만 생성·이미 생성한 텍스트 복사에는 적용하지 않는다. 여러 형식을 연속으로 요청해도 실제 전면 광고 표시 이후 10분 동안 추가 광고를 생략한다.

기존 피치 중심 화면·버튼·배너를 보존하고 내보내기 패널에 Android용 안내만 추가하는 범위다. 새로운 화면이나 주요 시각 개편이 아니므로 콘셉트 3종을 새로 만들지 않는다. 사용자 요청이 이전 `.sq` 광고 제외 제안을 대체한다. 데이터 보관과 파일 백업을 구분하고, 광고 실패가 백업을 막지 않게 한다.

## 완료 기준

광고는 미리 준비하고, 준비되지 않았으면 기다리거나 뒤늦게 띄우지 않는다. GIF 인코딩 실패·잘못된 destination·공유 텍스트 생성 실패에서는 광고를 요청하지 않는다. 광고를 닫은 뒤 원래 저장·공유·텍스트 보기로 정확히 한 번 이어지며 중복 탭을 막는다. 선수·전술 데이터를 광고 플러그인에 보내지 않는다. 웹 회귀, native facade, Java 빈도 정책, Android 빌드·lint를 확인하고 새 서명 APK를 기존 GitHub `build/` 전달 경로에 반영한다. 실기기/실제 광고 노출 검증은 별도로 구분한다.
