## 실제 문제와 선택의 의미

- 현재 데스크톱 `.pane-field` 안의 280px 선수 도구 열과 별도 설정 열이 폭을 함께 소비한다. ①은 목록 / 피치 / 설정의 외부 구조로 통합한다.
- 844×390에서 세로 피치·헤더·도구가 길게 쌓인다. 수평 피치와 선택 도구를 같은 화면에 놓고 부가 설정은 접근 가능한 스크롤로 유지한다.
- PNG는 피치 안에 임시 팀명 배너를 얹고 GIF에는 팀명이 없다. 피치 밖의 상단 불투명 헤더에 실제 팀명을 표시한다.
- 프로토타입 왼쪽에는 전술 목록과 선수 목록이 있다. 운영에서는 실제 보관 파일의 기존 열기 계약과 선수 선택을 사용한다. 예시 파일·예시 선수·라벨만 바꾸는 상태 전환을 복사하지 않는다.
