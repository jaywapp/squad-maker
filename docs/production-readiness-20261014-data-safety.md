# Data safety 구현 대조 초안

2026-10-14. **Console 미제출**. 로컬 저장 기능과 SDK 처리를 분리해 조사한 후보표다. 최종 답안/보관 기간/법적 검토 완료를 추측하지 않는다. [개인정보 초안](production-readiness-20261014-privacy-draft.md), [출시 체크리스트](production-readiness-20261014-release-checklist.md)를 함께 사용한다.

[Google SDK 데이터 안내](https://developers.google.com/admob/android/privacy/play-data-disclosure)는 현재 사용한25.5.0과 일치한다. SDK가 처리하는 정보와 전송 목적/TLS를 설명하지만 최종 Console 답안을 대신하지 않는다. [Play Data safety 정의](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko)를 기준으로 수집/공유, 일시적 처리, 필수/선택과 목적을 항목별로 검토한다. 지역/사용자별 차이가 있다면 해당 앱의 전체 적용 범위를 확인한다.

## 잘못된 답안을 피할 기준

- 전술이 기기에만 저장된다는 이유로 모든 수집/공유 항목을 아니오로 답하지 않는다.
- 테스트 광고·비개인화·TEEN·UMP 선택이 있다고 모든 IP/ID/진단 처리가 사라졌다고 답하지 않는다.
- Google의 TLS 설명을 운영 제보 API 등 모든 경로의 전송 보안 검증으로 쓰지 않는다.
- SDK의 진단을 정확한 crash 범주로 자동 치환하거나 모든 처리를 일시적이라고 추정하지 않는다.
- 공유 예외/서비스 제공자 예외, 광고 ID 선택 가능성만으로 다른 처리의 선택 가능성을 확정하지 않는다.
- 회원 계정 생성 기능은 현재 없지만, 이를 공개 제보/지원 요청의 보관·삭제까지 없다는 뜻으로 쓰지 않는다. 임의의 90일 자동 삭제나 전체 삭제 가능성을 약속하지 않는다.
- 개인정보처리방침은 이 후보표/실제 산출물과 일치해야 한다. 실제 공개 페이지 이전에는 정책 URL을 만들어 연결하지 않는다.

## 제출 전 증거

최종 승인된 정식 앱의 merged manifest·SDK dependency·광고 요청 보호 설정·동의 메시지/기기 동작, 제보 API의 합성/허용된 실접수·공개 범위, 지원 운영/삭제 절차, 최종 공개 방침 URL을 보관한다. 지금은 정식 앱 ID/서명 미승인, 정책 URL 없음, 운영 광고·실기기 미검증이므로 Console 제출을 진행하지 않는다. AdMob 계정 인증·스토어 연결·심사도 별도 미완료다.
