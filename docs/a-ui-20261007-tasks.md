## 실행 기록

- 기준선(046f5f6, 수정 전): 단위 95/95, e2e 187 passed / 1 skipped(2.8분). Codex 기록과 같다.
- 1차 구현 후 회귀 실행은 **자원 부족 중단**: 시스템 메모리 부족으로 Claude Code가 백그라운드 테스트와 로컬 서버를 중단했다(테스트 실패 아님). 중단 전 e2e 106개 통과였으나 이후 코드가 바뀌어 최종 결과에 합산하지 않는다.
- 재개(사용자 지시): 가용 메모리(시작 시 약 1.0~1.4GB, 이후 4~6GB)와 Codex 활동(Gradle 데몬 대기, 잠금 파일 17:46 이후 갱신 없음, headless 에뮬레이터 실행 중)을 확인하고 무관한 프로세스는 종료하지 않았다. 내가 띄운 Playwright MCP 브라우저만 닫았다. 테스트는 포그라운드에서 `--workers=1 --project=…`로 순차 실행했다.
- 화면 검증 중 발견·수정: 숨은 경고 띠 버튼에 Tab이 닿음, 모바일 도움말·제보·인원·화살표 48px 미만, 200% 글자에서 팀명 입력 폭으로 가로 넘침과 헤더 압축, 트레이 "색상·더보기" 줄바꿈, 긴 이름표 겹침, 목록 시트가 열린 채 저장 상태가 바뀌면 다시 그려져 키보드 포커스 유실. flex 줄바꿈 시도가 기본 글자에서 피치를 밀어내는 회귀를 만들어 grid + rem 기준 container query로 되돌렸다.
- 최종 코드(index.html SHA-256 `D58A5A716C36F81B…`) 기준 순차 결과:
  1. 단위 `npm run test:unit`: 95/95
  2. 데스크톱 e2e `npx playwright test --project=desktop-1280 --workers=1`: 94 통과(3.0분)
  3. 모바일 e2e `npx playwright test --project=mobile-390 --workers=1`: 93 통과, 1 skip(기준선과 같은 mobile 전체 패턴 GIF)
  4. 화면 검증 `docs/a-ui-20261007/ui-verify.playwright.js`: 전 항목 통과. 결과 표는 [인계 4장](a-ui-20261007-handoff.md)
- 슬롯 가득 참: preview 기본 한도 없음 → 실제 동작에는 미적용. 계약이 허용한 테스트 주입으로만 표시를 확인했다.
- Android 번들 포함 확인: `.work/android-web/index.html`에 UI CSS·DOM·스크립트 표식 존재, Google Fonts 링크 제거.
