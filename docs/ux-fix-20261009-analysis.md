## 5. 가정

- 앱은 다크 테마 고정이며 라이트 모드는 범위 밖이다.
- `/api/feedback` 404는 로컬 정적 서버에 API가 없어서다. 제보 창구 오류 표시는 화면 처리만 고친다.
- 문구 변경(도움말·확인 버튼·em dash)은 기능 계약이 아니라 UI 문구다. 단, e2e가 문구로 요소를 찾는 곳은 테스트와 함께 바꾼다.

## 6. 범위와 비범위

- 범위(1단계): `index.html`의 CSS·마크업·문구·ARIA·작은 이벤트 처리. 관련 e2e 기대값 수정.
- 범위(2단계): 설계 3장의 패턴 화면 정돈과 키보드 이동.
- 범위(3단계): 콘셉트 3종 제작과 사용자 선택까지. 선택 후 운영 구현은 별도 작업계획으로 연다.
- 비범위: 저장·내보내기 계약(v2), 데이터 모델, 분석 이벤트, Android 네이티브 코드, 결제·수익화, 파비콘.
