## 고지 문구 (권장)

로고 글자는 그림이라 고지가 필수는 아니다. 앱의 오픈소스 고지(`app/licenses/`)에 아래 한 줄을 넣어 출처를 남기는 것을 권한다.

```text
IBM Plex Sans KR - Copyright © 2017 IBM Corp. with Reserved Font Name "Plex". Licensed under the SIL Open Font License, Version 1.1.
```

## 앱 본문 글꼴과의 관계

앱 본문은 이미 IBM Plex Sans KR(400/500/700)을 웹 글꼴로 쓴다. 로고와 본문이 같은 계열이라 별도 글꼴 의존이 생기지 않는다. Android 번들은 웹 글꼴 링크를 지우므로 본문은 기기 글꼴로 보이지만, 로고는 경로라 모든 환경에서 같은 모양이다.

## 비교했지만 쓰지 않은 글꼴

Pretendard 1.3.9 (SIL OFL 1.1, https://github.com/orioncactus/pretendard)는 선택되지 않은 B안에만 썼다. A안 자산에는 들어 있지 않다.
