# UI/UX 리디자인 — 분석

- 상태: **blocked — 2차 시안 선택 대기**
- orchestrator: Claude

## 요청
UI/UX·테마·디자인 전면 개편. 운영 구현 전 서로 다른 콘셉트 시안 3종을 아티팩트로 제공.

## 현재 상태와 근거
- 단일 파일 `index.html`(vanilla JS). 테마는 차콜 그린 배경 + 라임 강조색(`--bg #141a16`, `--accent #b8e986`)의 "전술 보드" 스타일, 중앙 정렬 세로 스택 레이아웃.
- `docs/2026-07-18-ui-ux-review.md`의 남은 과제: 되돌리기 부재(P1), 모바일 지침 입력 세로 길이(P1), 숨은 제스처(더블클릭·우클릭) 의존, 키보드·스크린리더 접근성.
- 현재 앱의 배경+강조색 조합은 흔한 "다크 + 형광 포인트" 패턴이라 제품 고유성이 약함.

## 질문 (사용자 확인 필요)
1. 3종 중 어떤 시안으로 진행할지, 또는 시안 간 조합(예: 03의 레이아웃 + 01의 테마)을 원하는지.
2. 다크/라이트 기본값 선호.
3. 개편 범위: 시각 스타일만 교체할지, 레이아웃·상호작용(되돌리기, 바텀시트, 단축키)까지 포함할지.
4. 공유 뷰어 모드·PNG/GIF 내보내기 이미지도 새 테마로 맞출지.

## 가정·제약
- `impeccable`, `design-taste-frontend` 스킬이 이 실행 환경에 설치되어 있지 않아 적용하지 못했다. 선택 후 운영 구현 단계에서 설치된 환경이라면 적용한다.
- 정적 단일 페이지라 Supabase 연동은 이번 범위가 아니다(기존 구조 유지).
- 시안은 프로토타입이며 저장·내보내기는 동작하지 않는다.

## 범위 / 비범위
- 범위: 시안 3종 제작·제시. 운영 `index.html` 변경 없음.
- 비범위: 선택 전 운영 구현, 배포.
