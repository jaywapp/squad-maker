# UX 개편 시안 3종 (ux-redesign-20261007)

계획 문서: [분석](../ux-redesign-20261007-analysis.md) · [설계](../ux-redesign-20261007-design.md) · [작업](../ux-redesign-20261007-tasks.md)

당시 상태: 사용자 선택 대기. 현재 상태: A 선택, B/C 미선택. 운영 `index.html`은 바뀌지 않았다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 세 시안 비교 페이지(스크린샷, 장단점, 비교 기준, 점검 결과, 추천) |
| [선택 A 원본](../../../design-a/prototype.html) | A 나이트피치: 다크 그린·라임, 피치 중심, 선택하면 나타나는 편집 도구 |
| `concept-02/index.html` | B 데이라이트코치: 밝은 고대비, 큰 글자, 선수 → 배치 → 움직임 단계 흐름 |
| `concept-03/index.html` | C 택틱스스튜디오: 네이비·코발트, 전술 파일 탐색과 키프레임 타임라인 |
| `shared/state.js` | 세 시안이 그대로 붙여 넣은 공통 데모 상태(우리 FC / 9v9 / 3-3-2) |
| `screenshots/` | 360×800(모바일 에뮬레이션), 1366×768 실제 렌더링 캡처 |

각 시안은 외부 스크립트가 없는 단일 HTML이다(Google Fonts만 불러온다). 실제 저장·다운로드·공유·광고·결제·계정·분석은 연결하지 않았고, 저장됨·처리 중·실패·되돌리기 상태에는 "시안" 표시가 붙는다. 각 시안 상단의 "시안 상태 보기"로 상태를 띄운다.

시안 파일은 브라우저로 직접 열어도 동작한다.

## 점검 (2026-10-07)

- 환경: Playwright MCP가 띄운 Chromium. 360×800은 `isMobile`·`hasTouch` 에뮬레이션이며 실제 Android 기기 검증이 아니다.
- 결과: 세 시안 모두 360px 가로 넘침 0, AA 대비 미달 텍스트 0, 스크립트 오류 0, 키보드 포커스 표시 확인, 터치 탭으로 선수 선택 확인, 360×800과 1366×768에서 피치와 선택 도구 동시 노출 확인(B는 배치 단계 기준).
- 48px 미만으로 남은 요소: A 기본·공격·수비 버튼 폭 44px, 각 시안 상단 "시안 상태 보기" 높이 44px, C 타임라인 단계 버튼 높이 44px.
- 미검증: 실제 Android 기기 터치·햇빛 가독성, TalkBack 실사용, 모든 상태 조합, 사용자 테스트.
