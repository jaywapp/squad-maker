# #59·#60 실제 Android 검증 대기

아래는 모두 **실기기 미검증**이다. Java helper 테스트와 브라우저 facade·viewport 변경·합성 이벤트는 실제 Documents provider·Activity 재생성·광고 SDK 검증이 아니다.

준비: 승인된 테스트 광고 빌드의 SHA·패키지·버전·서명, 기기/OS를 기록한다. 기존 모든 팀/전술은 각각 .sq로 백업한다. 신규 서명·기기 설치·앱 데이터 삭제는 이번 자동 작업에 포함하지 않는다. 운영 광고를 반복 노출하거나 클릭하지 않는다.
