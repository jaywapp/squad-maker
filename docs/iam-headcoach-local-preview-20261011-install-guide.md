# 아이엠 헤드코치 Preview APK 설치 안내

이 안내는 사용자가 최종 전달받은 로컬 Preview APK를 확인할 때 사용하는 절차다. 현재 실제 기기 설치·업데이트·데이터 유지와 아래 T7 항목은 **전부 미검증**이다. 이번 준비 작업이 기기를 조작하거나 설치하지는 않는다. 빌드·서명 검증 완료 여부와 최종 파일은 PR54 및 `.work/iam-headcoach-local-preview-20261011/final`의 실제 generation 기록을 먼저 확인한다. 이전 baseline APK나 예상 version1091을 최종 전달본으로 혼동하지 않는다.

## 설치 전 백업

1. 현재 앱의 모든 팀과 전술을 열어 각각 `.sq`로 내보낸다. 현재 팀/전술 수·이름과 주요 선수 배치·지침·패턴을 메모하거나 화면으로 남긴다.
2. 이미 보관 중인 `.sq`도 빠짐없이 복사한다. 새로 내보낸 파일과 기존 파일을 앱 밖의 폴더에 두고 PC에도 별도 복사한다. 앱을 제거하면 사라질 수 있는 내부 보관만 백업으로 사용하지 않는다.
3. 앱 밖/PC에서 파일 목록·파일 크기와 필요한 팀/전술이 모두 있는지 확인한다. 원본 백업은 유지하며 확인을 위해 덮어쓰지 않는다.
4. 휴대폰에 설치된 앱의 package·version과 제공 APK의 실제 identity를 비교할 수 있을 때 확인한다. 공개 baseline은 code1085이지만 현재 설치본의 version은 미확인이다. 더 높은 설치본이나 인증서 불일치가 보이면 업데이트를 진행하지 말고 정보를 기록한다.

## 앱 삭제 없이 업데이트

최종 전달 APK의 이름·source generation·hash 및 검증 기록을 확인한 뒤 휴대폰에서 해당 APK를 열어 기존 앱의 업데이트로 진행한다. Android가 해당 파일 출처의 설치 권한을 요청하면 필요한 출처에 한해 안내를 확인한다. APK package는 `com.jaywapp.squadmaker.preview`, 표시 이름은 `아이엠 헤드코치 Preview`여야 한다.

설치 오류·서명 불일치·version downgrade 경고가 나면 중단한다. **기존 앱을 삭제하거나 데이터/캐시를 초기화하거나 강제 downgrade하지 않는다.** 오류 문구, 설치본/전달본 version, Android 버전을 남기고 비교를 요청한다. 비밀번호·키·credential 값을 전달할 필요는 없다. 새 앱으로 별도 설치하거나 다른 package로 우회하는 절차는 제공하지 않는다.

## 업데이트 후 데이터 확인

업데이트가 완료됐을 때 기존 팀/전술의 수·이름·배치·지침·패턴을 설치 전 기록과 비교한다. 백업한 `.sq`를 앱의 불러오기·복원 절차로 열어 내용을 비교한다. 덮어쓰기를 안내하면 기존 자료 백업과 복원 대상부터 다시 확인한다. 작은 수정→저장→앱 재시작 뒤 수정이 유지되는지 확인한다. 확인 중 원본 백업은 그대로 보관한다. 자료가 사라지거나 저장/복원이 이상하면 추가 편집·덮어쓰기·삭제를 멈추고 관측을 남긴다.

## T7 실기기 확인표

모든 행의 현재 상태는 **미검증**이다. 아래 기대결과는 통과 증거가 아니며 실제 관측 뒤 결과/기기·Android 버전·화면 또는 간단한 재현 기록을 남긴다.

| 항목 | 기대결과 | 남길 증거 | 현재 상태 |
|---|---|---|---|
| 이름·아이콘 | 홈/설정에 아이엠 헤드코치 Preview와 기존 Run Line 아이콘 표시; 작은 라벨/마스크 잘림 확인 | 홈·앱 정보 화면, 기기/Android 버전 | 미검증 |
| 첫 실행 | 시스템 splash→한글 intro→전술 편집 순서로 진입 | 시작 화면 순서·멈춤 여부 | 미검증 |
| intro 탭 | 탭한 뒤 준비된 편집 화면으로 정상 진입 | 탭 시점·진입 여부 | 미검증 |
| 동작 줄이기 | OS의 동작 줄이기 설정에서 불필요한 모션 없이 진입 | 설정 상태·진입 관측 | 미검증 |
| 재진입 | 앱을 나갔다 돌아올 때 불필요한 cold intro 없이 편집/저장 상태 유지 | 돌아오기 전후 화면·자료 비교 | 미검증 |
| 회전·글자 확대 | 세로/가로·OS 글자 확대에서도 편집 행동이 가능하고 자료가 유지됨 | 전후 화면·조작/저장 관측 | 미검증 |
| 기존 자료·SQ | 모든 기존 팀/전술 유지, SQ 복원→수정→저장→재시작 후 내용 유지 | 팀/전술 수·대표 자료·재시작 비교 | 미검증 |

이 Preview APK의 기존 test 서명은 정식 Play 키 전략·출시·공개 배포를 뜻하지 않는다. package·공유 주소·광고·저장 형식은 변경하지 않는 범위다. 빌드/aapt/apksigner 결과는 실제 휴대폰의 launcher 잘림·저장 유지·설치 성공을 대신하지 않는다. 준비 범위·검증 방법은 [분석](iam-headcoach-local-preview-20261011-analysis.md), [설계](iam-headcoach-local-preview-20261011-design.md), [작업계획](iam-headcoach-local-preview-20261011-tasks.md)을 따른다.
