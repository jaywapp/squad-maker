# #61 실제 Android 공유 검증

아래 항목은 **모두 실기기 미검증**이다. 브라우저 facade·viewport 변경·합성 visibility/pageshow 이벤트와 실제 Activity/시스템 공유/광고 SDK는 별개다. 기기 설치·서명·실제 운영 광고 요청은 이번 작업에서 실행하지 않는다.

검증 전 모든 팀/전술을 각각 .sq로 백업한다. 테스트 광고 빌드와 승인된 설치 경로만 사용하고 앱 삭제·초기화·강제 다운그레이드로 오류를 해결하지 않는다. 광고 클릭 금지.

| 절차 | 기대 결과 | 증거 |
|---|---|---|
| 광고 ready/loading/no-fill/offline 상태별 PNG/GIF/.sq 공유와 텍스트 공유 | 파일/텍스트 준비 뒤 광고 없이 기존 모달/시스템 공유창. 실제 공유 전송은 사용자가 확인 | 기기/OS·빌드 SHA·광고 상태·화면 녹화 |
