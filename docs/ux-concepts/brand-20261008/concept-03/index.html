초크 피치

경기 전 화이트보드에 가장 먼저 긋는 두 선, 하프라인과 센터서클을 비틀어 스쿼드 메이커의 S를 만들었습니다.

센터서클을 하프라인 위아래로 나눠 한쪽은 올리고 한쪽은 내리면 S가 됩니다. 선수가 약속된 대로 자리를 옮기는 장면을 한 획에 담았고, 라임은 두 반원이 만나는 센터 스폿 한 점에만 씁니다.

시작 스플래시

시스템 스플래시는 같은 차콜 배경에 아이콘만 띄웁니다. 이어지는 앱 내 인트로에서 초크가 경기장을 긋고, 센터서클이 S로 갈라진 뒤 아이콘 자리로 줄어듭니다. 전체 1.5초, 동작 줄이기 설정이면 마지막 로고만 보입니다.

서체
한글 워드마크 Do Hyeon(OFL). 굵고 손으로 쓴 듯한 획이 초크 보드와 맞습니다. 영문 보조 Zilla Slab 700(OFL), 자간 0.28em. 앱 UI 글꼴(IBM Plex Sans KR)은 그대로 둡니다. Android 번들 적용 시 두 워드마크는 아웃라인 SVG로 바꿉니다.
최소 크기
일반 심볼은 28px 이상. 그보다 작으면 터치라인과 하프라인을 뺀 소형 심볼(24px)을 씁니다. 가로형은 높이 24px까지, 영문 보조줄은 높이 32px 이상에서만 붙입니다.
여백
심볼 높이의 1/4(S 한 칸 높이)을 사방 최소 여백으로 둡니다. 헤더에서는 바 높이 안에서 위아래 여백이 자동으로 확보됩니다.
