# 스쿼드 메이커 브랜드 시안 브리프 (2026-10-08)

대상: 앱 아이콘, 좌상단 로고, 시작 스플래시(모션). 시안 3종 비교용이며 운영 코드·Android 리소스는 아직 바꾸지 않는다.

## 1. 브랜드 전략

| 항목 | 내용 |
|---|---|
| 제품 | 조기축구·풋살 코치가 폰으로 선수 배치와 약속된 움직임(전술 패턴)을 만들고 이미지·GIF로 단톡방에 공유하는 전술 보드. Android 우선 |
| 사용자 | 동호회·아마추어 축구 감독·주장. 경기 전 운동장 옆, 밤 늦게 집에서 다음 경기 준비 |
| 약속 | "오늘 뛸 전술을 1분 안에 그려 팀에 보낸다." 정확하지만 어렵지 않다 |
| 성격 | 현장감, 명료함, 믿음직함, 약간의 승부욕. 장난스럽거나 e스포츠처럼 화려하지 않다 |
| 피할 것 | 축구공 클립아트, 트로피·월계관, 방패 엠블럼(클럽 문장처럼 보임), 번개, 실제 클럽·리그 로고와 닮은 형태, 흰 축구공 오각형 패턴 |
| 이미 확정된 시각 정체성 (A 나이트피치) | 배경 `#141a16`(차콜 그린), 표면 `#1c241e`, 피치 녹색 `#2b5e3f`, 초크 화이트 `#e8ede8`, 라임 강조 `#b8e986`(주 행동·선택에만), 숫자·워드마크 Oswald |

이 정체성 안에서 변주한다. 색을 완전히 바꾸는 시안은 만들지 않는다.

## 2. 산출물과 사양

### 2.1 좌상단 로고 (앱 헤더)
- 위치: 운영 앱 상단 바 왼쪽(현재 `h1.wordmark` "SQUAD MAKER 전술 보드" 자리). 배경 `#141a16`.
- 표시 높이: 모바일 24~28px, 데스크톱 28~32px. 이 크기에서 읽혀야 한다.
- 변형: (a) 심볼+워드마크 가로형, (b) 심볼 단독(좁은 화면용), (c) 한글 병기 여부 판단("스쿼드 메이커"). 앱 이름은 "스쿼드 메이커"(영문 SQUAD MAKER).
- 워드마크는 실제 글꼴로 조판한다(Oswald 등 Google Fonts). Android 번들은 Google Fonts를 지우므로 최종 적용 시 SVG 아웃라인으로 바꿀 것을 전제로 한다.

### 2.2 앱 아이콘 (Android adaptive icon)
- 108×108dp 캔버스, 안전 영역 지름 66dp 원 안에 심볼 핵심. 전경(foreground)과 배경(background) 분리.
- 단색 아이콘(Android 13 테마 아이콘)용 monochrome 레이어.
- 원형·스쿼클·둥근 사각 마스크 모두에서 균형, 48dp·24dp(알림·설정 목록)에서도 식별.
- Play 스토어 512×512 PNG(풀블리드, 마스크는 스토어가 적용).

### 2.3 시작 스플래시
Android 12 이상 시스템 스플래시는 GIF를 쓸 수 없다. 두 단계로 제안한다.
1. **시스템 스플래시(정적, 즉시)**: `windowSplashScreenBackground` 단색 + 아이콘(240dp, 안쪽 160dp 원 안에 보이게). 선택적으로 1000ms 이하 애니메이티드 벡터(AVD) 가능.
2. **앱 내 모션 인트로(웹, 1.2~1.6초)**: 시스템 스플래시가 끝난 직후 같은 배경에서 이어지는 모션 그래픽. 저장소 준비(`SquadMakerContract.ready()`)를 기다리는 동안 보여 주고, 끝나면 앱 화면으로. 탭으로 건너뛰기, `prefers-reduced-motion`이면 정적 로고만.
- 시안 확인·공유용으로 같은 모션을 GIF로도 만든다(리드가 렌더링).

## 3. 기술 제약 (모든 시안 공통)
- 시안 파일은 외부 스크립트 없는 단독 HTML. 외부 리소스는 Google Fonts 링크만.
- 로고·아이콘은 직접 그린 SVG(단순 기하 마크). 래스터 이미지·이모지 금지.
- 모션은 **CSS 애니메이션 또는 Web Animations API만** 사용. `requestAnimationFrame` 루프·SMIL `<animate>`·JS 타이머 기반 프레임 금지(리드가 `document.getAnimations()`로 시간을 고정해 GIF 프레임을 뽑는다).
- 모션 길이 1200~1600ms, 마지막 상태(정지 로고)로 끝난다. 반복은 데모 페이지의 "다시 보기" 버튼으로.
- 문구는 한국어, em/en 대시 없음.
