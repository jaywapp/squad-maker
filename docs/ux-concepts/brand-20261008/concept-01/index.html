RUN LINE 시안 01, 런 라인

스쿼드 메이커에서 가장 자주 하는 일은 선수 한 명의 약속된 움직임을 긋는 것입니다. 그래서 마크는 그 한 동작입니다. 선수 토큰 하나와, 거기서 출발하는 점선 런 라인 하나.

전술판에서 점선 화살표는 공 없이 뛰는 움직임을 뜻합니다. 코치가 매일 그리는 기호를 그대로 앱의 얼굴로 씁니다.

헤더 로고

32px 이하에서는 점선 사이 간격이 1px 아래로 줄어 뭉개집니다. 그래서 헤더는 실선 소형 심볼을 씁니다. 한글 병기는 높이 48px 이상 로고에서만 합니다.

Play 스토어 512. 풀블리드, 모서리는 스토어가 깎습니다. 240px로 축소 표시.

시작 스플래시

시스템 스플래시가 아이콘을 띄우고, 같은 배경 위에서 앱이 런 라인을 직접 긋습니다. 저장소 준비를 기다리는 1.4초 동안의 한 장면입니다.

1단계, 시스템 스플래시. 배경 #141a16, 아이콘 240dp 중 160dp 원만 보임.

2단계, 앱 내 모션 1400ms

  1. 0-260선수 토큰이 점에서 제 크기로 빠르게 자리 잡습니다.
  2. 180-780점선 런 라인이 토큰에서 출발해 끝까지 그어집니다.
  3. 740-920화살촉이 끝점에서 딱 맞물립니다.
  4. 900-1400마크가 왼쪽으로 비켜서고 워드마크가 그 뒤에서 나옵니다. 정지.

탭하면 건너뜁니다. 동작 줄이기 설정에서는 마지막 정지 로고만 보입니다. CSS 애니메이션만 써서 GIF 프레임을 그대로 뽑을 수 있습니다.
