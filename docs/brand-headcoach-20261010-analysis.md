## 1. 요청 (2026-10-10, 사용자)

- 기존 Run Line 디자인을 바탕으로 한글 브랜드 '아이엠 헤드코치' 전환 시안을 만든다.
- 기존 자산과 실제 앱 화면을 먼저 확인하고, 자료가 없으면 임의로 재현하지 말고 요청한다.
- 영어 브랜드를 앞세우지 않고 한글 가독성을 우선한다.
- 2안: 기존 색·심볼·분위기를 최대한 살린 최소 변경안 1개, 한글 로고 배치를 개선한 대안 1개.
- 헤더, 앱 아이콘, 스플래시, 인트로의 실제 작은 크기 적용 모습을 보인다. 아이콘에 긴 이름을 억지로 넣지 않아도 된다.
- 디자인 전체를 새로 만들거나 앱 기능·화면 구조를 바꾸지 않는다.
- 폰트는 상업적 사용과 앱 배포 라이선스를 확인하고 출처를 남긴다.
- 이름은 동명 서비스 검색에서 발견되지 않은 후보이며 국내 상표 확인이 남아 있다. 이번에는 시안까지만 하고, 사용자가 고른 뒤 최종 SVG/PNG, 폰트 정보, 색상값, 크기별 자산, 기존 파일 교체표를 Codex에 넘길 수 있게 정리한다.

## 3. 결정과 근거

- **콘셉트 수**: 레포 규칙은 주요 UX 변경 시 콘셉트 3종이지만, 사용자가 이번 요청에서 "총 2안"을 명시했다. 규칙의 "면제는 사용자가 명시한 경우만 허용"에 해당하므로 2안으로 진행한다. 서로 다른 방향이 되도록 A는 글자만 교체, B는 글자 배치 구조를 바꿨다.
- **아이콘**: 두 안 모두 Run Line 아이콘을 그대로 쓴다. 이름을 넣지 않는다(사용자 허용). 브랜드 전환의 변화는 워드마크와 앱 라벨에서 일어난다.
- **글꼴 전달 방식**: Android 번들은 Google Fonts를 제거하므로(`scripts/build-android-web.mjs`, Run Line 사양 §4) 워드마크는 Run Line과 같이 아웃라인 경로로 만든다. 앱에 글꼴 파일을 새로 싣지 않는다.
- **디자인 스킬**: impeccable(기존 시각 체계를 보존하는 범위의 작업으로 판단, PRODUCT.md 없이 기존 구현을 기준으로 진행)과 design-taste-frontend(보존형 리디자인, 기존 토큰 고정, em dash 금지)를 적용했다.

## 4. 폰트 라이선스 확인 (2026-10-10, 원문 직접 확인)

| 글꼴 | 버전·출처 | 라이선스 | 상업 사용·앱 배포 | 비고 |
|---|---|---|---|---|
| IBM Plex Sans KR (Bold, A안) | `google/fonts` `ofl/ibmplexsanskr/` (`OFL.txt`, `METADATA.pb`), 원 저장소 `IBM/plex` | SIL OFL 1.1 | 가능. 문서·앱·로고에 쓰고 함께 배포 가능. 글꼴 파일만 단독 판매 금지 | 예약 글꼴 이름 "Plex". 앱이 이미 웹 글꼴로 쓰는 계열 |
| Pretendard 1.3.9 (SemiBold·ExtraBold, B안) | `orioncactus/pretendard` `LICENSE`, 릴리스 `v1.3.9` `Pretendard-1.3.9.zip` | SIL OFL 1.1 | 가능. 조건 같음 | 예약 글꼴 이름 "Pretendard"(및 파생 원본 Source, Inter, M PLUS 1). 글꼴을 고쳐 재배포할 때만 이름 제한 |

로고는 글꼴을 경로로 바꾼 그림이라 OFL의 "글꼴 소프트웨어" 배포에 해당하지 않는다. 그래도 출처 기록을 위해 최종 인계 문서와 앱의 오픈소스 고지(`app/licenses/`)에 두 글꼴 이름과 라이선스를 남기는 것을 권한다(T-04).
