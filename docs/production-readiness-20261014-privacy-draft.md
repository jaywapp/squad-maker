## 기기에 저장하는 팀·전술

현재 앱은 서비스 회원 계정/팀 서버 자동 업로드 없이 팀·선수 이름, 선수 배치, 지침, 움직임 패턴 등 사용자가 작성한 전술을 기기에 저장한다. 이 내용에 본인이나 다른 사람을 식별하는 정보가 포함될 수 있다. 로컬 저장이라는 설명은 광고·제보 등 모든 외부 통신이 없다는 뜻이 아니다.

사용자가 선택하여 .sq 백업, 이미지, GIF, 텍스트 또는 공유 링크를 만들 수 있다. 공유받은 사람이 파일/링크의 내용을 볼 수 있으므로 공유 전에 이름·지침 등 공개 범위를 확인해야 한다. 앱은 사용자가 전달한 외부 파일/메신저/수신자 사본을 자동 삭제하지 않는다.

Preview와 정식 앱의 기기 저장소는 별개다. .sq는 현재 전술 하나의 편집 스냅샷으로, 전체 팀/전술 분류와 앱 설정·동의 정보를 모두 백업하지 않는다. 모든 전술을 각각 내보내고 앱 밖에 보관한 뒤 복원·수정·저장 여부를 확인한다. 삭제·초기화는 데이터 이전 절차가 아니다.

## Google AdMob 광고·SDK 데이터

Android 앱에는 Google Mobile Ads SDK25.5.0과 UMP4.0.0이 포함되어 있다. Preview·개발·자동 QA는 테스트 광고를 사용하며, 정식 운영 광고는 별도로 선택한 release 설정과 동의/광고 보호 검증을 거쳐 연결한다. 테스트 광고 사용도 SDK의 모든 네트워크/데이터 처리가 없다는 의미는 아니다.

Google 공식 SDK 안내에 따른 처리 범위는 광고·측정·부정 이용 방지를 위한 IP 주소(대략적인 위치 추정 가능), 앱/광고 상호작용, 성능·진단 정보, 광고 ID·app set ID 및 해당되는 기기/계정 식별자다. 해당 SDK 전송은 TLS로 암호화된다. 실제 수집/공유 범위와 선택 가능 여부는 최종 앱·동의/제한 광고·권한·계정 설정을 대조해야 한다. 비개인화/TEEN 설정이 적용되더라도 모든 식별자·위치·진단 처리가 사라진다고 설명하지 않는다. [SDK25.5 공식 공개 안내](https://developers.google.com/admob/android/privacy/play-data-disclosure).

Google의 별도 개인정보 안내: [Google 개인정보처리방침](https://policies.google.com/privacy), [Google 파트너 서비스의 정보 사용](https://policies.google.com/technologies/partner-sites). 광고 처리의 실제 수령자·국외 이전/위탁 항목과 보관/삭제 방식은 최종 설정 및 운영 정보를 확인해 보완해야 한다. 임의의 보관일수나 처리 국가를 확정하지 않는다.

## 동의·청소년 보호

앱은 UMP로 동의 정보를 갱신하고 필요한 화면을 제공하며, SDK의 광고 요청 허용 여부를 확인한다. 개인정보 옵션이 필요한 경우 도움말의 광고 개인정보 옵션으로 재진입할 수 있다. 필요 여부/제공 화면은 지역·계정 메시지·SDK 상태에 따라 달라지며, 모든 사용자에게 반드시 같은 팝업이 표시되는 것은 아니다.

현재 앱은 생년월일이나 사용자의 실제 연령을 수집/인증하지 않는다. Play 타겟 연령은 사용자별 연령 확인이나 광고 동의를 대신하지 않는다. 연령 보호안의 구현/승인 상태는 [현재 연령·광고 정책](production-readiness-20261014-audience-policy.md)을 따른다. UMP만으로 모든 연령·개인정보 의무가 해결됐다고 주장하지 않는다.

## 제보·이메일·웹 분석

- 앱 제보: 제보 API는 사용자가 작성한 제목·내용과 선택 연락처/진단을 공개 GitHub Issue로 전송한다. 별도 스팸 방지 검증은 Cloudflare Turnstile에 검증 토큰과 요청자의 IP 주소를 전송하며, API는 IP로 호출 빈도를 제한한다. 제보 본문/연락처/진단을 Turnstile 검증으로 보내는 구현은 아니다. 공개 Issue는 다른 사람도 볼 수 있으므로 비공개 정보는 제출하지 않는다. 운영 API/브라우저 Turnstile의 실제 처리 범위·수령자/보관·삭제 담당은 출시 전에 검증해야 한다.
- 지원 이메일: 사용자가 이메일로 문의하면 이메일 주소·본문·첨부 등이 이메일 제공자와 문의 처리 과정에서 사용될 수 있다. 회신/지원 처리 외 사용, 보관 기간·접근 권한·삭제 요청 처리 기준은 운영자가 확정해야 한다. 문의에 불필요한 선수·팀 개인정보를 첨부하지 않도록 안내한다.
- 웹 분석: Umami ID가 주입된 웹에서만 설정된 분석 이벤트를 보낸다. 팀·선수·전술 내용을 분석 이벤트에 넣지 않는 계약과 광고 SDK 처리는 별개다. 현재 Android bundle의 웹 분석은 비활성이다. 웹 운영 범위/호스팅 로그·분석 제공자 정보는 실제 공개 사이트에 맞게 보완한다.
- 기존 코치 인터뷰 모집: 현재 별도 모집 이메일 링크가 있다. 지원 이메일로 일괄 변경하지 않았으며 실제 모집 운영·문의 목적/보관 기준은 별도로 확인한다.

## 보관·삭제·사용자 요청

기기에 있는 전술은 사용자가 관리한다. 삭제 작업 전에 필요한 .sq 백업을 보관해야 한다. 앱 전환·업데이트 문제를 해결하기 위해 삭제·데이터 초기화를 안내하지 않는다. OS/기기·앱 삭제 시 로컬 데이터가 영향을 받을 수 있으며 외부 백업 사본과 공유 파일은 별개다.

공개 제보·이메일 지원·SDK의 보관/삭제를 로컬 전술 삭제와 같다고 설명하지 않는다. 개인정보 문의와 정정/삭제 요청 창구 후보는 기존 공개 지원 blueheart.dev@gmail.com이다. 담당 지정·실제 요청 처리 절차·본인 확인 최소 범위·외부 사업자 요청 방법·법적 보관 사유/기한은 운영자 확인 후 게시한다. 확인되지 않은 자동 삭제/복구 가능성을 약속하지 않는다.
