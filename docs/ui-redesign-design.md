# UI/UX 리디자인 — 설계

- 상태: **blocked — 시안 선택 대기** (선택 후 확정)

## 시안 구조
- `docs/ux-concepts/ui-redesign/shared/core.js`: 세 시안 공통 데이터·포메이션 배치·드래그·패턴 보간·공유 텍스트.
- `concept-0N/src.html`: 시안별 마크업·스타일·렌더러. `/*@CORE@*/` 위치에 공통 코어를 인라인한다.
- `concept-0N/index.html`: 빌드 결과(브라우저에서 바로 열 수 있는 단일 파일).
- 좌표계: x 0–100(좌→우), y 0–100(상대 골문 위 → 우리 골문 아래). 시안 02는 가로 피치로 변환(`left = 100 − y`, `top = x`), 640px 미만에서는 세로로 전환.

## 시안별 설계 포인트
- 01 자석 전술판: 피치가 잔디가 아닌 화이트보드 마커 라인. 선수 = 자석, 지침 = 포스트잇. 화면 전환은 하단 마커 트레이(엄지 영역).
- 02 매치데이 중계: 정보 위계를 중계 그래픽 문법(스코어버그 → 스테이지 → 하단 자막 → 티커)으로 표현. 선택 선수는 하단 자막으로 즉시 편집.
- 03 전술 워크스페이스: 편집 도구 문법. 선택 → 속성 패널, 방향키 미세 이동, 모든 파괴적 변경에 5초 되돌리기 토스트(UX 점검 P1 대응), 모바일은 바텀시트.

## 운영 반영 시 검토 항목(선택 후 확정)
- 기존 CSS 토큰(`:root`)을 선택 시안 토큰으로 교체, 버튼 계열(`btn-*`) 정리.
- html2canvas PNG·gif.js GIF 렌더링 색상과 폰트 일치 여부.
- 기존 Playwright e2e 셀렉터(`.app-tab`, `.squad-tab` 등) 호환.
- 웹폰트 로딩 실패 시 시스템 폰트 폴백.
