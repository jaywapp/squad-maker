# ⚽ 스쿼드 메이커

축구 포메이션과 선수 지침을 작성하고, 움직임 패턴을 이미지·GIF·공유 링크로 전달하는 웹앱입니다.

[라이브 웹앱](https://squad-maker.vercel.app/) · **[최신 문서 안내](docs/README.md)**

## 제품 방향과 구현 상태

사용자가 **A — 피치 중심 코치형**을 선택했습니다. Android 첫 출시의 상세 기획과 미정 결정은 [상품 기획서](docs/product-plan.md)에 있습니다. 1차는 로그인 없이 편집·기기 저장·이미지/GIF 저장과 공유·광고를 목표로 합니다. 무료 슬롯은 동시에 보관하는 재사용 가능한 공간이고 삭제하면 다시 쓰며, 수정·자동저장은 차감하지 않습니다. 추가 슬롯은 단건 결제로 영구 확장하는 방향입니다. 수량·가격·슬롯 단위·결제 시점·Android 프레임워크는 아직 미정입니다.

현재 운영 앱은 HTML/CSS/JavaScript 단일 파일 웹앱입니다. Android 앱·다중 팀/전술 파일 보관·광고·결제가 구현됐다는 뜻은 아닙니다. [현재 웹 구현·실행·검증 참고](docs/current-web-reference.md), [A 원본과 예정 개선](docs/design-a/README.md)을 구분해서 읽어 주세요.

## 현재 웹 주요 기능

- 5~11인제 포메이션, 기본·공격·수비 스쿼드, 선수 배치·이름·색상·지침
- 선수와 공의 다단계 움직임 패턴, 미리보기, 단일/전체 패턴 GIF
- PNG 이미지, 전술 텍스트, 매치 전략, .sq 편집 원본 백업
- URL 스냅샷 공유와 비회원 읽기 전용 뷰어
- LocalStorage에 마지막 작업 자동저장

인원 변경·초기화·.sq 복원의 데이터 보호 과제는 [최신 기획의 우선 보호 계획](docs/product-plan.md#11-우선-재현보호-계획)에 기록했습니다. 현재 해결된 것으로 표시하지 않습니다.
