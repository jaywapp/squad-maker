        전술

          아직 출시 전인 기능입니다. 어떤 기능부터 만들지 결정하기 위해 관심을 측정하고 있으며, 지금 쓰고 계신 무료 기능은 그대로 무료로 유지됩니다.
            이 창을 연 클릭만 관심 신호로 집계하며, 개인정보는 수집하지 않습니다.
            더 자세한 의견을 주고 싶다면 코치 인터뷰에 이메일로 참여할 수 있습니다. 이메일 주소는 인터뷰 연락에만 사용하고 분석 데이터에는 포함하지 않습니다.

            아이엠 헤드코치 사용 안내

            배치: 스쿼드 짜기

            1. 위쪽 배치 / 움직임 패턴 / 매치 전략 탭에서 배치를 고릅니다.
            2. 인원과 포메이션을 고릅니다. 인원을 바꾸면 이름·배치·지침·움직임 패턴이 초기화되므로 확인창을 먼저 읽어 주세요.
            3. 포메이션을 선택하면 선수들이 기본 위치로 배치됩니다.
            4. 선수를 탭하거나 클릭하면 선수 도구가 열립니다. 모바일에서는 선수 도구의 이름 / 색상 / 지침 / 삭제를 사용하세요. 작은 가로 화면은 번호 중심으로 표시하며 선택한 선수의 전체 이름을 도구에서 확인합니다.
            5. 선수를 끌어 원하는 자리로 옮기면 그 선수가 선택됩니다. 데스크톱의 더블클릭은 이름 편집, 우클릭과 모바일 길게 누르기는 선수 메뉴입니다.

            지침 적기

            • 기본 / 공격 / 수비마다 전체 지침과 선수별 지침을 적을 수 있습니다. 선수 도구의 지침을 누르면 해당 선수 입력으로 이동합니다.
            • 선수 시점 보기 버튼이나 선수 메뉴에서 선수 기준 위치와 지침을 봅니다.

            움직임 패턴과 매치 전략

            • 움직임 패턴에서 선수·공을 끌어 경로를 그리고 + 단계로 이어 갑니다. 미리보기로 순서대로 재생합니다.
            • 매치 전략에서 상대팀과 경기 정보를 적고 전술 지침서 생성으로 전달할 내용을 만듭니다.

            공유하기

            • 위쪽 내보내기·공유를 누르면 이미지·GIF·링크·텍스트·백업을 고르는 시트가 열립니다.
            • 단톡방 공유 텍스트 생성으로 메신저에 붙여 넣을 요약과 링크를 만듭니다.
            • 받은 사람이 링크를 열면 읽기 전용 화면으로 보이며, 그 사람의 데이터는 건드리지 않습니다.

            전술 목록과 저장

            • 위쪽 전술 목록에서 팀과 전술을 고르고 새 전술을 만들거나 이름을 바꿀 수 있습니다.
            • 보관된 전술의 변경 내용은 자동 저장됩니다. 저장 실패나 중단 안내가 나오면 다시 저장하거나 백업을 받아 두세요.
            • 백업 파일 저장 (.sq)으로 편집 가능한 원본을 받고, 백업에서 복원으로 가져옵니다. 복원은 현재 전술을 교체하므로 확인창을 읽어 주세요.
            • 이미지와 GIF는 전달용 결과물입니다. 편집 데이터 복원에는 .sq 백업 파일이 필요합니다.
